# Headless nopCommerce

Ein Projekt zur Umsetzung einer Headless-Commerce-Architektur auf Basis von nopCommerce. Ziel ist es, das Shop-Backend von der Präsentationsschicht zu entkoppeln und ein eigenständiges Frontend über APIs anzubinden.

🎯 Ziele
Nutzung von nopCommerce als E-Commerce-Backend
Entkopplung von Backend und Frontend
Kommunikation über REST APIs
Flexible Integration eines modernen Frontends, z. B. mit Next.js
Individuelle Anpassung von Produkten, Warenkorb, Checkout und Kundenverwaltung
🛠️ Technologie-Stack
Backend: nopCommerce / ASP.NET Core
API: REST / JSON
Frontend: Next.js oder eine vergleichbare Frontend-Technologie
Datenbank: Microsoft SQL Server
🚧 Herausforderungen
Bereitstellung fehlender oder zusätzlicher API-Endpunkte
Authentifizierung und Verwaltung von Kundensitzungen
Warenkorb, Checkout und Zahlungsintegration
Synchronisierung von Preisen, Lagerbeständen und Kundendaten
CORS, Fehlerbehandlung und API-Versionierung
Updates und Wartbarkeit individueller nopCommerce-Anpassungen
📍 Projektstatus

Das Projekt befindet sich in der Entwicklung. Der Fokus liegt zunächst auf der technischen Grundlage für eine stabile Headless-Architektur.

🚀 Roadmap
nopCommerce einrichten
API-Zugriff und Authentifizierung konfigurieren
Frontend anbinden
Produktkatalog und Produktdetails implementieren
Warenkorb und Checkout integrieren
Kundenkonto und Bestellverwaltung ergänzen
Tests und Deployment vorbereiten
📄 Lizenz

Die Lizenz des Projekts sowie die Lizenzbedingungen von nopCommerce und verwendeten Drittanbieter-Komponenten sind separat zu beachten.
